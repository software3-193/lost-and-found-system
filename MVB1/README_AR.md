# نظام المفقودات — نسخة MVP (Laravel 12)

## وظائف النسخة الحالية
- تسجيل حساب طالب وتسجيل الدخول والخروج.
- إضافة بلاغ عن غرض مفقود أو غرض تم العثور عليه.
- حفظ البلاغات بحالة «قيد المراجعة» حتى يراجعها المدير.
- عرض البلاغات المنشورة والبحث بالكلمة المفتاحية والفئة ونوع البلاغ والتاريخ.
- تقديم طلب إثبات ملكية لغرض تم العثور عليه.
- مراجعة المدير للبلاغات وقبولها أو رفضها.
- مراجعة طلبات إثبات الملكية، تأكيد الملكية، ثم تسجيل تسليم الغرض.
- إغلاق البلاغ تلقائياً بعد تسجيل التسليم.

## المتطلبات
- PHP 8.2 أو أحدث.
- Composer.
- MySQL (مثل XAMPP) أو SQLite.

## التشغيل السريع على Windows
1. تأكد من تثبيت PHP 8.2+ وComposer وإضافتهما إلى PATH (يمكن استخدام PHP الخاص بـ XAMPP).
2. انقر مرتين على `START-WINDOWS.bat`. سيقوم بتثبيت الاعتماديات، إنشاء ملف البيئة وقاعدة SQLite، تشغيل الترحيلات وإنشاء حساب المدير، ثم تشغيل الموقع.
3. افتح `http://127.0.0.1:8000`.

> التشغيل السريع يستخدم SQLite ولا يحتاج إلى إعداد MySQL أو phpMyAdmin.

## التشغيل اليدوي على Windows / XAMPP
1. فك ضغط المشروع داخل `C:\xampp\htdocs`.
2. افتح Terminal داخل مجلد المشروع.
3. ثبّت اعتماديات PHP:

   ```bash
   composer install
   ```

4. أنشئ ملف البيئة:

   ```bash
   copy .env.example .env
   ```

5. افتح `.env` واضبط قاعدة البيانات. مثال MySQL:

   ```env
   APP_NAME="Lost and Found System"
   APP_LOCALE=ar
   APP_FALLBACK_LOCALE=ar
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=lostfound
   DB_USERNAME=root
   DB_PASSWORD=
   SESSION_DRIVER=file
   CACHE_STORE=file
   QUEUE_CONNECTION=sync
   ```

   أنشئ قاعدة بيانات باسم `lostfound` من phpMyAdmin قبل المتابعة.

6. أنشئ مفتاح التطبيق:

   ```bash
   php artisan key:generate
   ```

7. أنشئ الجداول وحساب المدير التجريبي:

   ```bash
   php artisan migrate --seed
   ```

8. شغّل المشروع:

   ```bash
   php artisan serve
   ```

9. افتح `http://127.0.0.1:8000`.

## حساب المدير التجريبي
- البريد الإلكتروني: `admin@lostfound.test`
- كلمة المرور: `Admin@12345`

غيّر كلمة مرور المدير بعد أول تسجيل دخول في أي نشر فعلي. هذا الحساب مخصص للتجربة المحلية فقط.

## سير العمل
1. ينشئ الطالب حساباً ويسجل الدخول.
2. يضيف بلاغاً ويختار «مفقود» أو «تم العثور عليه».
3. يبقى البلاغ قيد المراجعة ولا يظهر للطلاب حتى يوافق المدير على نشره.
4. تظهر البلاغات المنشورة في القائمة، ويمكن البحث بالفئة والتاريخ.
5. إذا تعرّف الطالب على غرض معثور عليه، يرسل تفاصيل إثبات الملكية.
6. يراجع المدير الطلب ويؤكد الملكية أو يرفض الطلب.
7. بعد التسليم الفعلي، يسجل المدير التسليم لإغلاق البلاغ.
